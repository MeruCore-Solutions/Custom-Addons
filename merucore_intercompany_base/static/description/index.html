Odoo 19 Base Module

MeruCore Intercompany Control Center - Base

Build reliable intercompany foundations before you automate documents. This addon gives your team company-pair rules, transaction oversight, audit history, issue tracking, and safe retry hooks in one multi-company-aware control center.

Business Problem

Intercompany automations often fail because there is no neutral control layer between source and destination companies. Teams need visibility, traceability, and governed retry behavior before they add business-specific generation logic.

Core Features

Transaction Control Center

Track each intercompany synchronization as a single auditable transaction record across both companies.

Company-Pair Configuration

Create directional rules with responsible users, retry limits, delay policy, and notification preferences.

Exception And Retry Handling

Use a controlled retry wizard, bounded retry cron jobs, and extension-ready retry handlers.

Immutable Audit Trail

Log synchronization, warning, error, retry, and state-change events without allowing silent tampering.

Security And Isolation

Expose records only when users can access both sides of the company pair, with manager-only technical details.

Extension Foundation

Future MeruCore modules can inherit the mixin and register business-specific retry and health handlers.

What This Module Includes

  • Intercompany transactions with health state, retry count, and source or destination document metadata.
  • Directional company-pair rules with responsible ownership and optional automatic retry.
  • Immutable intercompany audit events with resolve and reopen support.
  • Issue-focused menus for transactions that need attention.
  • Reusable mixin methods for future sale, purchase, stock, and accounting extensions.

Installation And Configuration

Step 1 Install the addon in an Odoo 19 database with the standard base and mail dependencies available.
Step 2 Enable intercompany support on the companies that will participate in governed intercompany flows.
Step 3 Create company-pair rules and assign the responsible intercompany users or managers.
Step 4 Connect extension addons later when you are ready to automate specific intercompany document flows.
